ALGORITHM selects Kick, Chatter or ROOT. EDIT shapes the draft sound. SEQ: tap a lower key to turn its step on or off. Hold a step to open TRIG LOCK; SELECT switches Sound, ENV and Notes / velocity. Turn the knobs to edit only that step. Press SEQ to close the menu. HOME’s recovery page offers Undo. REC arms the selected track; KNOB1 chooses Hits, Motion or Both (changing mode finishes the take). REC again finishes. PLAY works on every screen. Hold HOME for Panic.

Hardware control map and simulator limits

SELECT switches subpages on HOME, SEQ, ENV and FX. HOME's second page offers Undo, Rejoin and Panic. ENV shapes each organism; SELECT opens draft velocity and ROOT pitch/gate/slide. Hold a SEQ step to open its trig-lock menu; SELECT changes the lock page. SEL auditions the note/velocity page. FX controls track send; its global page describes the existing fixed delay. GLO opens tempo, Swing and Human. SAVE, PRESETS, ARP and LFO are reserved, with explicit status screens. The screen is a display, not a touchscreen. This is a browser control-map prototype using the shared C/WASM engine; its screen/menu code has not yet been ported to the FM1.
