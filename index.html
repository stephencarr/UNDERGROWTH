ALGORITHM selects Kick, Chatter or ROOT. EDIT shapes the draft sound. SEQ: tap an empty lower key to stamp that sound; tap an occupied step to select it, or hold it while turning a knob to edit its locks. SELECT switches between sound and step actions; choose Stamp, Erase or Undo with KNOB1, then SEL applies. REC arms the selected track; KNOB1 chooses Hits, Motion or Both (changing mode finishes the take). REC again finishes. PLAY works on every screen. Hold HOME for Panic.

Hardware control map and simulator limits

SELECT switches subpages on HOME, SEQ, ENV and FX. HOME's second page offers Undo, Rejoin and Panic. ENV shapes each organism; SELECT opens draft velocity and ROOT pitch/gate/slide. In SEQ, SELECT opens step actions, note/velocity, then environment locks. SEL auditions the note/velocity page. FX controls track send; its global page describes the existing fixed delay. GLO opens tempo, Swing and Human. SAVE, PRESETS, ARP and LFO are reserved, with explicit status screens. The screen is a display, not a touchscreen. This is a browser control-map prototype using the shared C/WASM engine; its screen/menu code has not yet been ported to the FM1.
